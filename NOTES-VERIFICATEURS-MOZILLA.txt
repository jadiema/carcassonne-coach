Notes pour les vérificateurs de Mozilla (addons.mozilla.org)
À coller, en anglais, dans « Notes pour les réviseurs » à chaque nouvelle version.
--------------------------------------------------------------------------------

carcassonne-coach analyses finished games and replays of Carcassonne on Board Game Arena
(analysis is disabled during games in progress). All computation runs locally; no data is
collected or sent anywhere. The only network access is an optional local server
(127.0.0.1:5555) used for faster analysis when the user runs it.

The engine (carcassonne_engine.py, browser_coach.py, neural_evaluator.py, torch_free.py:
plain, unminified Python) runs in a Web Worker through Pyodide.

Third-party code, unmodified, from the official Pyodide 0.26.4 release:
https://github.com/pyodide/pyodide/releases/tag/0.26.4 (pyodide-0.26.4.tar.bz2)
- pyodide/pyodide.js, pyodide.asm.js, pyodide.asm.wasm, python_stdlib.zip, pyodide-lock.json
- pyodide/numpy-1.26.4-cp312-cp312-pyodide_2024_0_wasm32.whl
The eval warnings come from Emscripten-generated code in pyodide.asm.js. 'wasm-unsafe-eval'
is required to compile the WebAssembly runtime.

carcassonne_model.pt contains only neural-network weights (numbers), read in Python with
NumPy; it contains no executable code. Source code: https://github.com/jadiema/carcassonne-coach
(GPL v3).

How to test: create a free Board Game Arena account, open the replay of any finished
Carcassonne game (game page > "Replay"), click the 🏰 button at the bottom right,
then "Analyser". Recommended moves are highlighted on the board after 15 seconds.
During a game in progress, analysis is intentionally blocked.


Links to the author's book and welcome page (new in the next version)

Version 3.1.0 - "Probabilities" tab

New tab in the coach panel showing tile-draw probabilities for the position on screen
(how many tiles of each family remain in the bag, chance of drawing one in the next k
draws, entropy), as explained in the author's book on Carcassonne.
- New file probabilites.js (plain, unminified JavaScript, loaded as a content script before
  content-script.js): pure arithmetic, no DOM access, no network access.
- The tab reads the game state through the same function as the analysis, so it obeys the
  same access rule as version 3.0.4 (finished games and replays only; blocked otherwise).
- "Holes on the board" asks the engine which remaining tiles can legally be placed on a few
  empty squares (new message "board-holes" from the content script to the background script,
  handled by the same Web Worker, or by the optional local server at 127.0.0.1:5555). The
  background script, worker and server refuse it unless the position is marked as finished.
- The panel header (tiles placed / remaining, scores) now follows the replay position.
No new permission, no new host, no remote code, no data collection.

How to test: open the replay of a finished Carcassonne game, click the 🏰 button, then the
"Probabilités" tab, and move through the replay: the figures update with each move.


Version 3.0.4 - Analysis restricted to finished games (unchanged in 3.1.0)

The extension only analyses finished games and replays, in line with Board Game Arena's
rules. Analysis is denied by default and allowed only on positive proof that the game is
over: a replay page path (/archive/replay/ or /tablereplay), BGA's archive mode flag, or the
game state "gameEnd". If none of these can be read, analysis is blocked.
The check is applied at every entry point (analysis button, JSON copy and save, automatic
export) and again by the engine itself (background script, worker and optional local
server), which refuse any position not marked as finished.

How to test: open a game in progress on boardgamearena.com, as a player or a spectator:
the panel shows that analysis is unavailable. Open a replay of a finished game: analysis works.
